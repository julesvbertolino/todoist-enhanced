# Mockup reference

- `mockup.html`: the markup and inline styles of the interactive mockup. It is
  a design-canvas file, so it will not run on its own. Read it for layout,
  copy, spacing and colours. The live version is
  https://claude.ai/artifact/LHfKugyzbVptcxhSUKiSmJ.
- `mockup-logic.js`: the mockup's state, sample data and rules, written for
  the mockup only. Use the sample data for demo mode (Phase 9) and the rules
  to understand intent. The real rules are specified in `../DATA-MODEL.md` §3.

The mockup's date is fixed at Tue 29 Sep 2026, and its people, KPI numbers and
most customers are sample data.
